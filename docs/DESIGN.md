# ゲーム設計書 — SORT FACTORY（v3: 推理パズル）

## 0. ここまでの経緯
| 版 | 内容 | 試遊結果 |
|---|---|---|
| v1 | 流れてくる荷物をリアルタイムで仕分け | 面白くない・爽快感がない（判断が浅いのに急かされる） |
| v2 | レーンを崩して出荷を連鎖させる手順パズル | 爽快感が足りない（「解けた」という手応えが残らない） |
| **v3** | **手がかりから箱の位置を理詰めで確定させる推理パズル** | 再試遊で確認する |

v2 までの反省: 「うまくいった／いかなかった」はあっても、**自分の頭で答えにたどり着いた**という感覚がなかった。
v3 は「答えは1つ・当てずっぽう不要・一手ごとに理由がある」推理パズルにし、最後の1個を置いた瞬間に全トラックが出荷される山場を作る。

## 1. ルール（積み込みパズル）
n×n の倉庫にトラックが停まっている。次の3つをすべて満たすように箱を置く。

1. **トラック1台につき箱1個**。箱はそのトラックの上下左右のとなりに置く（箱とトラックは1対1）。
2. **箱どうしは隣り合わない**（ななめも不可）。
3. **外側の数字** ＝ その行・列に入る箱の数。

操作: マスをタップで「箱 → ×（箱なしのメモ）→ 消す」。なぞって連続入力も可。
時間制限なし、ミスの罰なし、失敗なし。箱の配置が正解と一致した瞬間にクリア。

※ 論理パズルの定番ジャンル（数字の手がかり＋配置制約）に属する。テーマ・見た目・演出・ヒントの仕組みは独自。

## 2. 「考えて解けた」を成立させる仕組み
- **解は必ず1つ**: 全ステージを総当たりで検証（生成時の Python と、テスト時の Dart の独立した2実装）。
- **当てずっぽう不要**: 生成時に人間と同じ推理ルールだけで解けることを確認し、必要な推理の段階（tier）を記録。
  - tier 1 数える: 「この列はあと2個、置けるマスも2個 → 確定」「このトラックの空きは1マスだけ → 確定」
  - tier 2 並びで決まる: 「3マス並びに2個 → 両はしで確定」
  - tier 3 もしもの推理: 「ここに置くと別の列が足りなくなる → ×で確定」
- **雑務は自動化**: トラックのとなりでないマス、箱のまわり8マス、満杯の行・列には薄い×が自動で付く。プレイヤーは推理だけに集中できる。
- **間違いはその場で見える**: ルール違反の箱は赤枠、数字は「達成＝緑／超過＝赤」。
- **ヒントは理由つき**: 答えを教えるのではなく「なぜそこが確定するか」を文章で示し、根拠の行・列・トラックを光らせる。間違った箱があればまずそれを指摘する（`lib/game/logic/deduction.dart`）。

### ルールをわかりやすくする工夫（2026-11-15 追加）
試遊で「今までで一番いいが、もう少しわかりやすいルールに」との声を受けて追加。
- **ステージ1は案内つき**: 光るマスを順にタップするだけで1問解ける。毎手「なぜそこか」を短い文で表示。
- **置けないマスには置けない**: ルール違反になるマスをタップしても箱は置かれず、理由（「トラックの上下左右のとなりにしか置けません」「箱どうしはくっつけられません（ななめもダメ）」など）を赤い帯で表示。
- **箱とトラックのペアが見える**: 置いた箱はペアになったトラックの色に染まり、線でつながり、トラックに✓が付く →「1台に1個」が見てわかる。
- **ルール早見をアイコンつきに**、チュートリアル文・ヒント文を短く平易に（「上から3行目」ではなく、光っている行を指して説明）。

## 3. 達成感の演出
- 行・列の数字がそろうと緑に弾んで効果音（小さな達成を積み重ねる）。
- **フィナーレ**: 最後の箱を置くと、箱が順番にトラックへ飛び乗り、トラックの色に染まって次々に走り去る。音程が1台ごとに上がり、最後に紙吹雪と「ALL SHIPPED!」。
- ★3 ＝ ヒントなしで解いた証。★が欠けたステージは「★3に挑戦」で再挑戦できる。

| 区分 | ステージ | 盤面 | 必要な推理 |

| EASY | 1〜7 | 4×4〜6×6 | 数える（tier 1）。1〜3は練習（ヒント無料・★に影響なし） |

## 7. デイリーパズル（2026-11-16 追加）
「つい開く」習慣を作るための毎日1問。

| 項目 | 仕様 |
|---|---|
| 出題 | 端末のローカル日付で決まる1問。全員同じ問題 |
| 難しさ | 曜日で変化：月 6×6 かんたん → 火 6×6 → 水・木 7×7 ふつう → 金 7×7 ちょいむず → 土・日 8×8 むずかしい |
| 問題数 | 7曜日×53問＝371問（`assets/stages/daily.json`）。約1年は同じ問題が出ない |
| 品質 | 全問「解が1つ・推理だけで解ける」を生成時に検証。テストでも全問ヒントだけで解けること＋抜き取りで一意性を再検証 |
| 報酬 | 初回クリアのみ 50コイン＋連続日数×10（最大+70）。配送センター強化で増額。再挑戦はベストタイムのみ更新 |
| 連続日数 | 今日（未クリアなら昨日）からさかのぼって連続した日数。タイトルのカードに直近7日の達成ドット |
| 共有 | クリア画面「結果をコピーして共有」：日付・タイム・ヒント回数・連続日数・URL（答えは含まない） |
| その他 | ステージの解放・★とは独立。デイリーミッションに「今日のパズルを解く」を追加 |

選出ロジック: `pools[曜日][(基準月曜からの週数) % 53]`（`lib/game/logic/daily.dart`）。

## 8. リマインド通知（2026-11-16 追加）
デイリーパズルの習慣づけを後押しする、端末内のローカル通知（サーバー不要）。

| 項目 | 仕様 |
|---|---|
| 許可の求め方 | 起動直後には聞かない。**初めて今日のパズルを解いた直後**に、クリア画面の中で「明日のパズルをお知らせしますか？」と1回だけ提案。断られたら二度と出さない（設定からはいつでもオン） |
| 時刻 | 初期値 19:30。設定で変更可 |
| 届き方 | 1日1回だけ。**今日のパズルを解いた日は届かない**。時刻を過ぎた日も翌日から |
| 文面 | 連続記録があれば「🔥N日連続中！ 今日のパズルを解いて記録をのばそう」、なければ「◯曜日は「かんたん」。1問だけ解いてみませんか？」 |
| 予約方法 | 向こう7日分を1回ずつ予約し、起動時・デイリークリア時・設定変更時に作り直す。**1週間遊ばなければ自然に止まる**（しつこくしない） |
| Web版 | 通知なし（設定に「アプリ版で使えます」と表示） |
| 分析 | `reminder_opt_in`(granted) / `reminder_declined` / `reminder_opt_out` / `reminder_time` / `reminder_open`(cold) |

実装: 計画 `lib/services/notifications/reminder_planner.dart`（純ロジック・テスト済み）、端末への予約 `reminder_service.dart`（flutter_local_notifications）、つなぎ `reminder_manager.dart`。

## 9. 過去問カレンダー（2026-11-16 追加）
解き逃した日の「今日のパズル」をあとから遊べるカレンダー（タイトルの今日のパズルカードのカレンダーアイコンから）。

| 項目 | 仕様 |
|---|---|
| 範囲 | 直近28日（`ProgressController.pastDays`） |
| 解き逃した日 | **リワード広告を見る** か **100コイン** で開ける。一度開けた日はずっと遊べる |
| 解いた日 | 何度でも無料で再挑戦（ベストタイム更新） |
| 報酬 | 過去問の初回クリアは20コイン（今日の分は50＋連続ボーナス） |
| 連続日数 | **その日のうちに解いた日だけ** 数える。過去問で連続記録は埋め合わせできない（毎日開く理由を残すため） |
| 表示 | その日に解いた日＝濃い緑✓、あとから解いた日＝薄い緑✓、今日＝黄色枠、開けられる日＝🔒、未来・範囲外＝薄く表示。解いた日はタイムも表示 |
| 分析 | `past_unlock`(method: ad/coins)、`daily_clear` は過去問でも送る |

収益面: 広告を見る自然な動機（解き逃した日を遊びたい）と、コインの使い道の両方になる。
