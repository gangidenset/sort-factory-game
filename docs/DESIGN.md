# ゲーム設計書 — SORT FACTORY（v2: ターン制パズル）

## 0. v1 からの方針転換（2026-11-11）
v1 は「流れてくる荷物をリアルタイムで仕分ける」ゲームだった。試遊の結果「面白くない・爽快感がない」。
原因の分析:

| 問題 | v1 | v2 での対策 |
|---|---|---|
| 判断が浅い | 「色が合うか」を見るだけの作業 | どのレーンから崩すか、先を読むパズルにする |
| ストレスが先に来る | 時間・詰まり・ミスで常に急かされる | 時間制限なし。自分のペースで考える |
| 山場がない | 「+100」の小さな表示だけ | 出荷が連鎖する仕組み＋大きな演出・上がっていく効果音 |
| 無機質 | 色の箱だけ | 荷物とトラックに顔をつけ、愛着が湧く見た目に |

## 1. コアループ
```
ステージ選択 → 1ステージ1〜3分の考えるパズル → クリア（★1〜3）→ コイン・XP → 工場強化/収集 → 次へ
                       ↑ 戻す（無料1回＋広告）/ ヒント（広告）/ 復活（広告）
★3を狙ってリトライ ─┘
```

## 2. ルール
```
 NEXT ▭▭▭ 残り5台       ← 次に来るトラックの順番
 [🚚 赤 ▢▢▢][🚚 青 ▢▢▢]   ← 駐車中のトラック（2〜3台）
 棚 [□][□][□][□][□]      ← 行き場のない荷物の一時置き場
 |■| |■| |■| |■|          ← レーン（一番上が先頭）。レーンをタップ
 |■| |■| |■| |■|
```
1. **レーンをタップ**すると、先頭の荷物が同じ色の駐車中トラックへ自動で飛ぶ（同色が複数なら積載が多い方）。
2. 同じ色のトラックがいなければ**棚**へ置かれる。棚が満杯の状態で行き場がないと**失敗**（棚があふれた）。
3. トラックは満載で**出荷**。`NEXT` の先頭のトラックが入ってくる。
4. 入ってきたトラックは**棚から同じ色の荷物を自動で積む** → また満載なら出荷 → … これが**連鎖**。
5. 全トラックを出荷すればクリア。時間制限・ミス判定なし。

### パズルの深さを出す要素
- `NEXT` の順番が見えている → 「次の次」に来る色を見越して棚に置く/置かないを決める。
- 棚は少ない（HARDで3〜4）→ 置き場所の取り合い。
- 連鎖は「棚にためる」ことで狙える → リスクとリターンの判断。
- ★3は「棚に置いた回数 ≦ par（ソルバーが求めた最小値）」→ クリアした後も最適解を探すリトライ動機。

### ギミック（段階的に追加）
| ギミック | 内容 | 初出 |
|---|---|---|
| 見えない荷物 | 「?」の箱は先頭に来るまで色が分からない（めくれる演出） | 8 |
| 閉ざされたレーン | 鍵付き。表示台数を出荷すると開く | 11 |
| 大型トラック | 4個積み | 15 |

### スコア
荷物1個 +10、出荷 +100×連鎖段数（1台目100、2連鎖目200…）、クリア +200 + 空き棚×50。

### 救済（収益導線）
| 機能 | 無料 | 広告 |
|---|---|---|
| 戻す（1手） | 1回/ステージ（強化で+1/+2） | 追加で何回でも |
| ヒント | ステージ1〜3は無料 | ソルバーの解の最初の1手のレーンを光らせる |
| 復活 | — | 致命的な1手を取り消し＋棚+1（1ステージ1回） |

## 3. ステージ設計（30ステージ）
`python3 tool/gen_stages.py` → `assets/stages/stages.json`（レイアウトは明示的にJSONで保存＝手編集も可能）。

生成方法:
1. 仕様（レーン数・トラック台数・色数・棚サイズ・ギミック・**目標難易度**）ごとにランダム配置を最大60個作る。
2. **0-1 BFS ソルバー**で解けるか判定し、`par`（棚に置く最小回数）を計算。解けない配置は捨てる。
3. 「トラックに直接送れる手を優先し、それ以外はランダム」に打つ**なりゆきプレイヤー**を200回走らせ勝率を測る。
4. 勝率が目標に最も近い配置を採用。

テスト `test/game/stage_catalog_test.dart` が Dart 版ソルバーで全ステージの可解性を毎回再検証する（CIでも実行）。

| 区分 | ステージ | なりゆき勝率 | 内容 |
|---|---|---|---|
| EASY | 1〜10 | 100%→47% | 基本・棚・連鎖・NEXTを読む・見えない荷物 |
| NORMAL | 11〜20 | 66%→28% | 鍵レーン・5〜6色・2台ドック・大型トラック |
| HARD | 21〜30 | 21%→6% | 棚3〜4・全ギミック複合 |

詳細値は `docs/balance_report.txt`。なりゆきプレイヤーは「考えない人」の近似で、考えて打つ人間はもっと高い勝率になる想定（＝考えれば解ける）。試遊で調整する。

## 4. 演出（爽快感）
- タップした箱が弧を描いて飛び、トラックに入ると弾む（箱はトラック内で笑顔になる）。
- 出荷：トラックが加速して画面外へ → 次のトラックが左から入ってくる → 紙吹雪 → 「出荷!」。
- 連鎖：「2連鎖!」「3連鎖!」の文字が段数に応じて大きくなり、効果音の音程が上がる、画面が揺れる。
- 連鎖は内部では一瞬で計算し、盤面は**イベントを順番に再生**して見せる（`lib/game/flame/sort_factory_game.dart`）。再生中のタップは1つ先行入力として受け付ける。
- 次の一手でトラックに直接入る先頭の箱は光ってぷるぷる揺れる（判断の手がかり＋気持ちよさ）。
