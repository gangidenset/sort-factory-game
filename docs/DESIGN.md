# ゲーム設計書 — SORT FACTORY

## 1. コアループ

```
ステージ選択 → プレイ(30秒〜1分) → クリア/失敗 → 報酬(コイン・XP・★) → 工場強化/収集 → 次のステージ
                                   ↑ リワード広告: 復活 / コイン2倍 / ヒント
```

長期目標: 30ステージ制覇・★90個・工場レベル・コレクション（荷物デザイン/工場スキン/装飾）。
短期目標: デイリーミッション（毎日3つ、日付で決定的に選出）。

## 2. 画面構成（縦画面）

```
┌──────────────────────────┐
│ ⏸ STAGE 3 配送 4/14 ▓▓░ 1234 │ HUD（最小限）
│ ♥♥♡  5 COMBO   ⏱32秒 💡ヒント │
│                            │
│          ┃ □ ┃             │ コンベア（上から下へ流れる）
│          ┃ □ ┃             │
│  [保管]   ┃ □ ┃   [返品]     │
│  [保管]   ┗[■]┛            │ ■ = 仕分け対象（先頭）
│ ┌────┐┌────┐┌────┐┌────┐ │
│ │ 🟥 ││ 🟦★││ 🟩 ││ ★  │ │ ドック（要求条件・積載・NEXT）
│ │▮▮▯ ││▮▯▯ ││▯▯▯ ││▮▮▮▯│ │
│ └────┘└────┘└────┘└────┘ │
└──────────────────────────┘
```

- ゲーム画面はHUD以外すべてプレイエリア。広告バナー無し。
- 操作は「先頭の荷物をドックへ」1種類が基本。タップ（ドックを押す）とドラッグ（荷物を運ぶ）の両対応。
- 保管中の荷物はタップで選択 → ドックをタップ、またはドラッグ。
- タッチ領域は最小48px（320px幅端末でもテストで保証）。

## 3. ルール

| 要素 | 仕様 |
|---|---|
| 荷物 | 色（6色）、マーク（★●▲、ステージにより）、種類（通常/お急ぎ便/色変わり） |
| ドック | 要求条件 = 色 / マーク / 色＋マーク。容量（3〜4）に達すると出発し、NEXTの条件に入れ替わる |
| 正解 | +100点 + コンボ×10（最大+200）、お急ぎ便+50、色変わり+30、トラック満載+150 |
| ミス | 条件不一致の配送、お急ぎ便の時間切れ。コンボリセット。上限で失敗 |
| 返品 | ミスにならないがコンボリセット・得点なし |
| 失敗条件 | ミス上限 / ベルト満杯で詰まり / 制限時間切れ / 操作回数切れ |
| クリア | 目標配送数を達成した瞬間 |
| ★ | クリアで★1、スコアが理論最大の60%で★2、90%で★3 |
| 復活 | リワード広告で1回のみ。ミス→残り2回分回復、詰まり→後方3個撤去、時間→+15秒、手数→+5手 |

### パズル性を出す仕組み
- 荷物の一部（offRate）は「今開いているドックに合わない、NEXTのドックに合う」ように生成 → 保管して先回りすると得。
- 保管スロットは少なく（0〜3）、HARDでは保管・返品も1手として消費 → 「どれを取っておくか」の判断。
- 色変わり荷物は白いリングで切替タイミングを可視化 → タイミングを読む要素。
- マーク条件で「色だけ見て反射的に送る」ことを防ぐ。

### 公平性・再現性
- ステージごとのシード付き乱数（mulberry32）で生成。端末差が出ない。
- 荷物は「開いているドック」または「NEXT」に合わせて生成するため、理不尽な詰みが起きにくい。
- 全30ステージが「ヒント通りに操作する疑似プレイヤー」でクリア可能であることを自動テストで保証（`test/game/stage_catalog_test.dart`）。

## 4. ステージ設計（30ステージ）

`tool/gen_stages.py` → `assets/stages/stages.json`。JSONを直接編集しても良い（未指定項目はデフォルト値、読み込み時にバリデーション）。

| 区分 | ステージ | 主な導入要素 |
|---|---|---|
| EASY | 1〜10 | 基本(1)、トラック満載(2)、3ドック(3)、保管(4)、4色(6)、お急ぎ便(7)、コンボ(8)、返品(9)、試験(10) |
| NORMAL | 11〜20 | 4ドック＋保管2(11)、色変わり(12)、5色(13)、マーク(14)、制限時間(15)、混載(16)、マーク専用便(17)、ピーク(18)、高速色変わり(19)、試験(20) |
| HARD | 21〜30 | 操作回数制限(21〜)、6色、時限便ラッシュ、短いベルト、夜間配送（時間制限＋全ギミック）、ミス2回まで、高速ライン、最終試験(30) |

チュートリアルは各要素の初出ステージで1回だけカード表示（既読管理あり）。ステージ1〜2は正解ドックを光らせる（設定でOFF可）。

### バランス検証（`dart run tool/balance.dart`）
反応時間と誤答率の異なる3種の疑似プレイヤーで各30回プレイしたクリア率（抜粋、全体は `docs/balance_report.txt`）:

| ステージ | 熟練(0.6秒/誤2%) | 平均(0.9秒/誤6%) | カジュアル(1.2秒/誤10%) | 平均プレイ時間 |
|---|---|---|---|---|
| 1 | 100% | 100% | 97% | 約14秒 |
| 10 | 97% | 83% | 63% | 約32秒 |
| 20 | 97% | 70% | 47% | 約41秒 |
| 30 | 73% | 40% | 23% | 約40〜50秒 |

> 注意: 疑似プレイヤーは「マークを読む」「色変わりを待つ」などの認知負荷を再現しない。実際の人間はこれより難しく感じるはずなので、試遊で調整する（ROADMAP参照）。

## 5. 工場育成・コレクション

| 種類 | 内容 | 入手 |
|---|---|---|
| コンベア設備 Lv0-2 | ベルト容量+1/段階（詰まりにくい） | 200 / 500 コイン |
| 仕分け設備 Lv0-1 | 保管スロット+1（保管があるステージのみ、最大3） | 450 コイン |
| 配送センター Lv0-3 | ステージ報酬コイン+10%/段階 | 150 / 350 / 700 コイン |
| 工場スキン | スタンダード、ミント(300c)、サンセット(600c)、ナイト(★60)、ネオン(課金) | |
| 荷物デザイン（コレクション） | ダンボール、ギフト(St10)、木箱(St20)、カプセル(400c)、ゴールド(St30) | |
| 装飾 | 観葉植物/社旗/大時計/仕分けロボ(コイン)、金のトロフィー(★90) | |

報酬: クリア = (20 + ★×10 + 初回30) × (1 + 0.1×配送センターLv)、失敗 = 5コイン。
レベル: XP = スコア/20 (+10 クリア)。Lv n に必要な累計XP = 50·n·(n−1)。

## 6. デイリーミッション（簡易版）
毎日、プールから種類が重複しない3つを日付シードで選出（例: ステージを3回クリア / 連続正解10回 / お急ぎ便を5個配送 / 累計スコア15,000 / 荷物を60個配送）。達成で40〜60コイン。日付が変わるとリセット。
