# 試遊ガイド（Web版）

## URL
- 通常: https://gangidenset.github.io/sort-factory-game/
- 全ステージ開放（後半のバランス確認用）: https://gangidenset.github.io/sort-factory-game/?unlock=all

`main` にマージされるたびに GitHub Actions（`.github/workflows/web-playtest.yml`）が自動でビルド・テスト・公開します。

### 初回のみ必要な設定（リポジトリ管理者）
GitHub のリポジトリ → **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に変更。
その後 **Actions → CI / Web playtest → Run workflow** で手動実行するか、次の `main` へのマージで公開されます。

## 遊び方の案内（テスターに送る文面例）
> スマホのブラウザで上のURLを開いてください（PCでも可）。
> 縦画面で、ステージ1から順に10〜15分ほど遊んでください。
> 終わったら下の質問に答えてください。

## Web版の制限
- 広告・課金は動きません（復活ボタン・ショップは「利用不可」表示になります）。
- 進行データはブラウザ内（localStorage）に保存されます。別のブラウザや端末とは共有されません。
- 効果音はブラウザの仕様で、最初に画面をタップするまで鳴らないことがあります。
- iPhone Safari の場合、「ホーム画面に追加」すると全画面で遊べます。

## 観察ポイント（開発側）
- ステージ1のチュートリアルだけでルールを理解できたか（説明なしで最初の5個を正しく送れるか）
- タップとドラッグのどちらを使ったか
- 棚（2〜）・連鎖（3〜）・見えない荷物（8〜）・鍵レーン（11〜）のルールが伝わるか
- 連鎖が起きた瞬間に気持ちよさそうか（声が出る・笑う等）
- どのステージで失敗したか、「戻す」「ヒント」をどこで使ったか
- ★3を狙って自発的にリトライしたか
- 「もう1回」と自発的にリトライしたか、どこで遊ぶのをやめたか

3. ルールで分かりにくかったことは？（1つでも）

5. 「もう1回やりたい」と思った瞬間／やめたくなった瞬間
